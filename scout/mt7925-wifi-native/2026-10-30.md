# mt7925-wifi-native: 2026-10-30 (full run, window 2026-10-29 10:04 UTC to 2026-10-30)

## Notable

**[DrogaBox/RTL8814Native](https://github.com/DrogaBox/RTL8814Native): AWDL notes for a native Skywalk driver on
Tahoe 25G241.** 51 commits, almost all documentation from hardware tests on one RTL8814AU adapter. What they found:
- `wifip2pd` asks for a role 6 interface, and the generic `createVirtualInterface` accepts only role 7. They create
  `awdl0` from the kext.
- Ioctls 130 and 131 go through an `AF_INET6` socket, not the IO80211 user client. Returning 102 is enough.
- A Skywalk TX submission queue needs a non-null action (`initWithPool` rejects null), starts disabled, and has to be
  enabled in `enable()`.
- Acknowledging 18 peer-manager setters lets `configure` and `enableAWDL` complete. AirDrop itself is untested, since
  they have no Apple peer.
- `Tools/awdl_offsets_25G241.tsv` lists 61 offsets with byte patterns from the kernelcache.

Our native front end does not do AWDL yet, so these notes are the best map we have for it. We run 25G332, so every
offset needs rechecking. The project carries Realtek's GPL-2.0 header, so we read it and do not copy code. Medium to
High confidence.
