# mt7925-wifi-native: 2026-10-27 (full run, window 2026-10-23 23:28 to 2026-10-27 09:30 UTC)

## Actionable

**macOS 26.7.2 is build 25G330, and MtkWlanNative only loads on 25G241.** A user reports Wi-Fi and Bluetooth gone after
updating to 26.7.2 ([mt7925-hackintosh-wifi#4](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi/issues/4)).
The build number comes from [timliudev/NUC8intosh](https://github.com/timliudev/NUC8intosh), whose README records an
update from 25G325 to 25G330 dated 2026-10-26. MtkWlanNative builds its interface headers per macOS build and refuses
to load on any build it has no headers for (see `docs/HOW-IT-WORKS.md`); the only shipped set is 25G241. So on 26.7.2
the native front end stays out and Wi-Fi should fall back to the Ethernet-style `en1`. The same EFI reports
AirportItlwm and IntelBluetoothFirmware working on 25G330 with SIP on, which argues against a general IO80211 or
signing change. Fix: dump the headers on a 25G330 machine with `tools/kcabi/dump.py` and build for it. High confidence
on the pin, Medium that it is the whole story until we see the reporter's logs.

ga403wm-hackintosh, split into its own repo with history. Native Wi-Fi menu on Tahoe 25G241 with per-build ABI folders
like ours, 176.6 Mbit/s down and 65 Mbit/s up on a ROG Zephyrus G14, and AWDL work in progress on a `dev/awdl` branch
(our issue 2 asks for AWDL). Hardware layer re-implemented from Linux mt76; no code from our repos found. Clear BSD
licence.

**DGBooth/AirportRTW89-MT7922** ([repo](https://github.com/DGBooth/AirportRTW89-MT7922)): MT7922 as a native AirPort
device on Tahoe through OCLP's legacy IO80211 stack, 138 to 148 Mbit/s on one AMD machine. A different route from ours
(we use the Skywalk family that ships with Tahoe). GPL-2.0.

## Second run (Mac, window 2026-10-27 09:29 to 18:11 UTC)


### Actionable

**macOS 26.7.2 (25G332) and MtkWlanNative, with logs.** zld96969 (an ASUS ROG Strix B860-G board) posted five terminal
captures on [mt7925-hackintosh-wifi#4](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi/issues/4). On
25G332 (IO80211 1200.13.1) MtkWlanNative does not attach, MtkWlan falls back to its Ethernet-style `en1`, and `mtkwifi`
can still join a network. That matches what the per-build ABI design predicts: the kext only attaches on builds it has
headers for (25G241). The logs went through the redactor into the research repo
(`logs/zld96969/asus-rog-strix-b860-g-gaming-wifi-s/`). The fix needs the `abi/native-wifi` dump redone for 25G332 on a
Mac. We acknowledged the report
([comment](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi/issues/4#issuecomment-6450251365)) and added
the limit to the MtkWlanNative README
([d802610](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi-native/commit/d802610051c87592a92a29dc102c72e7f886a2c3)).
High confidence on the symptom, Medium on the cause until the dump is compared.

### Notable

- Apple's [macOS 26.7.2 notes](https://support.apple.com/en-us/149522) (26 Oct) list fixes in Bluetooth (a null
  pointer denial of service), Wi-Fi and AirPort, USB (a device that can crash the system or read kernel memory),
  IOKit and several kernel use-after-free bugs. The USB hardening is one plausible reason the MediaTek Bluetooth USB
  device is missing on 25G332, but nothing ties the two together. Medium confidence on the content (read through a
  summarising fetch), Low on any link to the symptom.
- [JoMei9019-real/AirPort-RTW](https://github.com/JoMei9019-real/AirPort-RTW) (GPL-2.0): a native AirPort driver for
  Realtek PCIe cards on Tahoe through the same OCLP legacy stack (restored IOSkywalkFamily and IO80211FamilyLegacy,
  AMFIPass). 1.1.0 adds 802.11k and v roaming and an AWDL transmit gate. No code in the repo, install guide only. We
  credited it in the MtkWlanNative README. It is the other route to a native menu: ship the old stack instead of
  matching each build.
- [HungLe17/AirBridgeRTL](https://github.com/HungLe17/AirBridgeRTL): an RTL8852BE Wi-Fi, Bluetooth and AWDL port forked
  from AirPort_RTW89, development preview, its own candidate unverified.
- [mnnobre/AirportMtkWlan#2](https://github.com/mnnobre/AirportMtkWlan/issues/2): an MT7922 kext that does not load at
  all on 26.7.1; the reporter points at a MaxKernel of 24.99.99 and Sequoia-built IO80211 headers. A duplicate of a
  problem MtkWlanNative already avoids by pinning the ABI per build.
- OCLP, itlwm and OCLP-CustoMac have no release that mentions 26.7.1, 26.7.2 or 25G332 (Medium confidence; the release
  pages show no year).
