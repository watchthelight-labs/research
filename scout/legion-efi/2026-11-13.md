# legion-efi: 2026-11-11 to 2026-11-13

Read from GitHub only. Nothing below is reproduced on our machine.

- **A Linux Legion tool shows CPU power limits on an Arrow Lake HX Legion are set through a Lenovo WMI "custom" mode.** LenovoLegionLinux 0.1.6 (merged 2026-11-13) fixes the Legion Pro 5 16IAX10H (83LU, Core Ultra 9 275HX): with the wrong driver bound to the GameZone WMI block, PL1 and PL2 could not be read or written. Tested values: PL1 range 50 to 135 W, PL2 60 to 210 W, writes in custom mode reach the MMIO RAPL limit at once, and the firmware keeps balanced mode's 70/125 W if custom is entered from balanced until the values are written again. Our machine is the 83F0 (BIOS S2CN26WW), a different model line, and the PR itself says the 83F3 probably needs the same flag but is untested, so nothing here is proven for the 83F0. It is a hint about firmware behaviour to keep in mind for LegionCpuPower power-limit work. GPL-2.0, ideas only. Confidence: Medium.
