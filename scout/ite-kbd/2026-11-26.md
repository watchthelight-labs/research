# ite-kbd: 2026-11-21 to 2026-11-26

Read from GitHub only.

- **New: a native macOS RGB app and CLI for Legion 4-zone keyboards that talks to the ITE USB controller directly.** It avoids the Input Monitoring block that `IOHIDManager` hits by using the USB device itself. It lists eleven controllers (048D C955 to C995) and uses a 33-byte 0xCC feature report. Tested on one LOQ 15IRX9 (048D:C993) on macOS 26.7.3 ([repo](https://github.com/TejasLamba2006/Legion-RGB-macOS), MIT, one day old, one star). Our controller is 048D:C195 (ITE 8258), which is not in its table and is a different generation, so it does not apply as is. The idea of going straight to USB for backlight control may. Confidence: Medium for the claim on their unit, Unverified for anything on ours.
