# Upstream scout run, 2026-11-21

Targets: all eleven. Window: 2026-11-13 16:20 UTC (nvgfx: 2026-11-14 14:14 UTC) to 2026-11-21. Full run with pull
requests and a web sweep. 47 known repositories had changes and 45 new candidates turned up, 6 of them related, plus
4 related repositories we learned about from comments and readers. Read from GitHub only; nothing here is reproduced on our
machine, and our test laptop cannot run macOS at the moment.

## Actionable

- A Panther Lake tester found that a compatibility layer which treats SRCU as plain RCU panics when `drm_dev_enter`
  sleeps under it. Our shim pins RCU readers in a critical section, so we have to check whether any SRCU reader of
  ours sleeps. It is also a new candidate for our long-run rendezvous panic. Write-up: [xe](../xe/2026-11-21.md).
- [intel-gpu-macos-driver 0.1.7](https://github.com/yusufklncc/intel-gpu-macos-driver/releases/tag/v0.1.7) fixes an
  ANV descriptor-buffer bug that drops a layer from app icons, with a test. Same plugin family as ours. Next: read
  the Mesa patch against our ANV tree and run the icon test on the Intel panel.
- Linux mt76 has the station channel-switch sequence our Wi-Fi driver lacks. Next: port it (ISC) for the drop on a
  channel change. Write-up: [mt7925-wifi](../mt7925-wifi/2026-11-21.md).
- The MT7925 Bluetooth loss after a warm restart looks like a controller power state: two other projects describe it
  and one names the firmware ErP setting. Next: test whether Windows also loses the controller after a warm restart,
  and look for the setting. Write-up: [mt7925-bt](../mt7925-bt/2026-11-21.md).
- [VoodooI2C #591](https://github.com/VoodooI2C/VoodooI2C/issues/591): a level-triggered GPIO pin is reported as
  edge-triggered and interrupts stall. Next: read the touchpad's GPIO interrupt declaration in our DSDT before
  finishing the VoodooGPIO change. Write-up: [i2c](../i2c/2026-11-21.md).
- NullMoth 3.0 is out. Its hybrid-panel fix is on main but missing from the package. Next: rebase, and build
  NMIntelFB from source. Write-up: [nvgfx](../nvgfx/2026-11-21.md).
- FreeBSD drm-kmod [PR 531](https://github.com/freebsd/drm-kmod/pull/531) clears the GGTT when i915 unloads. Next:
  port it.

## Notable

- The ThinkPad E16 owner tried the real `xe` driver (MeowXE3) on Arrow Lake-H, got whole-machine freezes, and went
  back to XeGfx.
- A second Arrow Lake-H user reports the panics stop with the HWP part of LegionCpuPower off. No panic file yet.
- WhateverXe 0.8.3 has a small BSD-3 eDP AUX backlight header, not yet validated on a panel.
- mt76 has no firmware roaming, so roaming is a host-side job on macOS too.
- AirportMtkWlan 2.2.2: exact firmware-ready test and a longer driver-ownership wait fixed its warm reboot.
- ForbiddenItlwm: SHA-256 key derivation label length, and a deauth on leave.
- NVIDIA open modules 620.73.04 is the tag to pin for a 620 rebuild.
- LenovoLegionLinux: on machine type 83F0 fans and temperatures go through WMI, and fan-table writes are not known
  to be safe. Write-up: [legion-efi](../legion-efi/2026-11-21.md).
- VoodooHDA 4.1 with embedded IOAudioFamily reported on Tahoe 26.7.1, with two build fixes.
