# Upstream scout run: 2026-10-27

Full run, all eleven targets. Windows: 2026-10-23 23:28 UTC to 2026-10-27 09:29 UTC for every target except xe
(from 2026-10-24 12:36 UTC). 379 API calls to collect, 0 errors; deep reading split over five readers.

## Actionable

1. **macOS 26.7.2 (25G330) and our Wi-Fi and Bluetooth.** A user reports both gone after the update
   ([mt7925-hackintosh-wifi#4](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi/issues/4)). MtkWlanNative
   only loads on builds it has headers for (25G241), and LegionBtFix was patched against 25G241 too. Needs headers
   dumped on 25G330 and a LegionBtFix check, both on a Mac. See [mt7925-wifi-native](../mt7925-wifi-native/2026-10-27.md)
   and [mt7925-bt](../mt7925-bt/2026-10-27.md).
2. **Our drag fix measured on an RTX 5080, with an OpenGL regression**
   ([nullmoth#412](https://github.com/nullmoth/nvidia-macos-driver/issues/412)): the stalls go away, but two state-cache
   commits break Alacritty text. See [nvgfx](../nvgfx/2026-10-27.md).
3. **zep245/IrisXe-macos-driver**: a working i915 and ANV driver on Tiger Lake with written answers for a sandbox
   problem like our I-106 and kernel panics like our I-116. See [xe](../xe/2026-10-27.md).
4. **Brightness persistence** ([PR #312](https://github.com/nullmoth/nvidia-macos-driver/pull/312)) is verified on an
   RTX 5080 Laptop; unmerged and unlicensed, so ideas only.
