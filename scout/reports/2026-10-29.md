## Actionable

- **nvgfx:** NullMoth [v2.6.4](https://github.com/nullmoth/nvidia-macos-driver/releases/tag/v2.6.4) changes only the translator. It lowers sampler arrays, and texture array elements now read their own texture. Most of what our fork carries on 2.6.2 shipped upstream in 2.6.3, so the next rebase goes straight onto 2.6.4. What stays ours: the PSO skip, the sampler-variant memo, the NVRM power work and the NVRMFB proxy head. Write-up: [nvgfx](../nvgfx/2026-10-29.md).
- **xe:** zep245's [IrisXe-macos-driver 1.0.1](https://github.com/zep245/IrisXe-macos-driver/commit/66a5f7266dbaab34d18c9a1b77249c17386c7883) found the same cause for the Tahoe yellow icons as we did. It also fixed linked visible functions that inherited the caller's function constants. Our Metal plugin merges them the same way (`nvmtl_link_stage`), so we carry the same latent bug. Write-up: [xe](../xe/2026-10-29.md).
- **mt7925-wifi-native:** [RTL8814Native](https://github.com/DrogaBox/RTL8814Native) mapped most of what a driver must provide for AWDL: the capability bit, the virtual interface payload, the registration that wifip2pd waits for, and what the kernel peer manager does itself. It is the best reference so far for [wifi-native #2](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi-native/issues/2). It is GPL, so we use it for ideas only. Write-up: [mt7925-wifi-native](../mt7925-wifi-native/2026-10-29.md).
- **mt7925-wifi / mt7925-bt:** an HP Omen 16 user confirmed Wi-Fi and Bluetooth on 26.7.2 with MtkWlanNative 0.4.14, LegionBtFix 0.3.0 and MtkBt 0.2.4 ([#4](https://github.com/watchthelight-labs/mt7925-hackintosh-wifi/issues/4), now closed). Their guide [credits and links our repos](https://github.com/Game-5040/hackintosh-hp-8f06-macos26/commit/92620db824033103b00b943f988c2dfae71ef0be). It has two stale lines and a possible country code question. Write-ups: [mt7925-wifi](../mt7925-wifi/2026-10-29.md), [mt7925-bt](../mt7925-bt/2026-10-29.md).
