# i2c: 2026-10-27 (full run, window 2026-10-23 23:28 to 2026-10-27 09:30 UTC)

## Notable

**VoodooI2C: first code change in eleven months.** [6be653a](https://github.com/VoodooI2C/VoodooI2C/commit/6be653a2d2)
(PR #586) adds I2C and GPIO support for Tiger Lake, Alder Lake and Raptor Lake, fixes the Alder Lake-S GPIO interrupt
layout and moves the VoodooGPIO submodule. No Arrow Lake IDs. It touches the controller driver files our Arrow Lake
patches also change, so the next rebase needs a careful diff. High confidence.

**wsjj-official/EFI-2025Y9000P 1.0** ([release](https://github.com/wsjj-official/EFI-2025Y9000P/releases/tag/v0.5),
[ebc42e5](https://github.com/wsjj-official/EFI-2025Y9000P/commit/ebc42e5e10)): a single EFI for the Legion Y9000P IAX10H
(83F5, same CPU as ours). It patches VoodooI2C to keep both I2C resources from the speaker amp's `_CRS` (stock VoodooI2C
keeps one), adds `nvrmacpibl=1` for the backlight
([d3fca02](https://github.com/wsjj-official/EFI-2025Y9000P/commit/d3fca02aad)), which matches what we found, and moves
BE200 Wi-Fi to AirportItlwm 2.4.0. Their audio work is in [audio/2026-10-27.md](../audio/2026-10-27.md).
