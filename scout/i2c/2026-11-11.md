# i2c: 2026-10-30 to 2026-11-11

Read from GitHub only.

- [VoodooGPIO PR 20](https://github.com/VoodooI2C/VoodooGPIO/pull/20) (merged 2026-10-25) adds pin tables for Alder Lake-S, Alder Lake-N and Tiger Lake-H as one header per platform. That is the shape an Arrow Lake table would take. Which Linux pinctrl table matches Arrow Lake-HX is not checked. GPL-3.0.
- [VoodooI2C 0271bbd](https://github.com/VoodooI2C/VoodooI2C/commit/0271bbddda610fdbb553a37a7edf061054d1ff20) documents `-vi2c-force-polling` and the `force-polling` property. No code change.
- [wsjj-official/EFI-2025Y9000P](https://github.com/wsjj-official/EFI-2025Y9000P/blob/main/docs/BIOS-VERSIONS.md) (Legion Y9000P 2025, 83F5): the Goodix touchpad runs on forced polling there too, so nobody has interrupts on this platform yet. Its speakers need an AW88399 amplifier driver (ACPI id `AWDZ8399`, [driver](https://github.com/Ersiter/Legion-ALC287-AW88399-macOS)); our 83F0 ACPI dump has no such device.
