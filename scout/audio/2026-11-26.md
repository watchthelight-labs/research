# audio: 2026-11-21 to 2026-11-26

- **Two projects now boot Intel Sound Open Firmware from a macOS kext to get the internal microphone.** new-green's VoodooHDA-SOF is a VoodooHDA fork that boots `sof-adl.ri` on an HP ProBook 440 G9 (Alder Lake-P `8086:51C8`, Tahoe 26.7), replays the IPC messages Linux sends, and publishes a 2-channel DMIC at 48 kHz with a noise-reduced second input. Sleep is untested and the DMIC setup is a replay from that one machine ([repo](https://github.com/new-green/VoodooHDA-SOF), BSD-2-Clause). chxnathanaels reports LatSOF-Audio working on a ThinkPad T14 Gen 4 (Raptor Lake-P `8086:51CA`, `sof-rpl.ri`), claimed as the first Raptor Lake machine ([repo](https://github.com/chxnathanaels/RaptorLake_IntelDSP_Hackintosh)). Both speak IPC3 on the older cAVS DSP. Arrow Lake uses a newer DSP generation and a different firmware, so this shows the route and is not a drop-in. Since our audio is already a VoodooHDA build, new-green's fork is the closest template. Confidence: Medium (one machine each, own reports).
- **Smart-amp speakers over I2C work on one ThinkBook.** pandariayu drives two CS35L41 amps beside an ALC287 on a ThinkBook 16p Gen 4, locked to that subsystem ID ([repo](https://github.com/pandariayu/ThinkBook16p-Gen4-macOS-Speakers), no licence). It only matters if our ALC287 speakers sit behind such amps; reading the NHLT and ACPI first would tell. Confidence: Low.
