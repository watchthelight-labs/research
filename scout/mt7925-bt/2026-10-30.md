# mt7925-bt: 2026-10-30 (full run, window 2026-10-29 10:04 UTC to 2026-10-30)

## Actionable

**[SimpleMtkBtFw #2](https://github.com/flxxxxddd/SimpleMtkBtFw/issues/2): BLE HID pairing stalls on Tahoe with an
MT7922.** Tahoe's bluetoothd waits for LE PHY Update Complete and then LE Data Length Change before it starts SMP, and
the MT7922 sends neither. The reporter injects a PHY event and turns the Command Complete of a real `0x2022` into a
Data Length Change event. Intel cards show the same behaviour
([IntelBluetoothFirmware #514](https://github.com/OpenIntelWireless/IntelBluetoothFirmware/issues/514)). If a BLE
keyboard or mouse stalls during pairing on MtkBt with an MT7925, this is the first thing to check. GPL-3.0, so we take
the idea and the event layout only. High confidence on the symptom, Medium that the MT7925 behaves the same.
