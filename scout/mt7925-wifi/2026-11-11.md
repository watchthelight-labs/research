# mt7925-wifi and the native front end: 2026-11-10 to 2026-11-11

Read from GitHub only. Nothing below is reproduced on our machine.

- HE association on the MT7927 port. [qqwqtzd/mt7927-hackintosh PORTING.md](https://github.com/qqwqtzd/mt7927-hackintosh/blob/main/PORTING.md), section 8, starts from our VHT-only join and adds HE capabilities (extension id 35) to the association request, `STA_REC_HE_V2` (tag 0x19), `UNI_BSS_INFO_HE_BASIC` (tag 5) and the AX phymode bits. It reports HE80 at 1032 Mbps and later HE160 at 2064 Mbps. System Information still says 802.11ac. Patches and binaries are published, the full source is not. Medium.
- IPv6 and multicast, same section: frames with header translation (RXD2 bit 7) were dropped on WPA2, so the interface saw no router advertisements. Worth checking on en1. Medium.
- Link quality. On Tahoe [ForbiddenItlwm](https://github.com/retropineaple/ForbiddenItlwm/blob/main/docs/HOW-IT-WORKS.md) (section 8) calls `IOSkywalkNetworkInterface::reportLinkQuality` every 2 s; without it the interface stays rated "off" and Apple Push never connects. GPL-2.0, so the idea only. Medium.
- AWDL. ForbiddenItlwm (about 22 MB/s with an iPhone on an Intel AX211), [thanhnndev's roadmap](https://github.com/thanhnndev/mt7925-macos/blob/main/docs/ROADMAP-AWDL.md) and an MT7922 reference all reuse Apple's AWDL engine in IO80211Family. None is shown working end to end on a MediaTek card.
- [thanhnndev/mt7925-macos](https://github.com/thanhnndev/mt7925-macos): a separate native MT7925 driver (Clear BSD, one ROG G14), reporting HE160 2x2 on 25G241.
- [xiaoyizpast/Hackintosh-OMEN-8f06 v1.2.7](https://github.com/xiaoyizpast/Hackintosh-OMEN-8f06): its WiFi Menu app now ships the `mtkwifi` from our 0.12.1 bundle.
- Web search for the window found nothing new.
