# mt7925-wifi: 2026-10-31 (full run, window 2026-10-30 16:00 UTC to 2026-10-31)

## Notable

**[qiqco/MT7922-macOS-Driver](https://github.com/qiqco/MT7922-macOS-Driver): a native Skywalk Wi-Fi and Bluetooth
driver for the MT7922 on macOS 26, binaries only.** No licence and no source (the README says source stays closed to
keep the developer motivated), so nothing to read beyond the README and release notes and nothing we can reuse. They
claim the Wi-Fi menu works, 5 GHz up to 80 MHz, 6 GHz not connecting, and AWDL "under test"; release
[1.2.37b2](https://github.com/qiqco/MT7922-macOS-Driver/releases/tag/1.2.37b2) says AirDrop is not fixed and that
`awdl0` may not release, which can block shutdown (roll back to the previous release). The README also reports a
1-in-5 to 1-in-20 panic after a warm reboot, which they guess is firmware load and unload. That resembles our own
warm-reset failure ([mt7925-hackintosh-wifi#1](https://github.com/watchthelight-labs/WTLMtkWireless/issues/1)).
For [#2](https://github.com/watchthelight-labs/WTLMtkWireless/issues/2) (other MediaTek cards) it is a lead,
not a source: we have not run or audited the binaries. Confidence: Low (unaudited claims).
