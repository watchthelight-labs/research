# IO80211 AWDL classes across macOS 26.7.1 to the 26.7.3 beta

Checked 2026-11-14. Source: our own `kcabi` dumps of `BootKernelExtensions.kc` on each build (slot tables read from the vtable symbols, instance sizes from the MetaClass constructors). Asked for by DrogaBox in [RTL8814Native #1](https://github.com/DrogaBox/RTL8814Native/issues/1).

| Class | Slots | Instance size | 25G241 | 25G332 | 25G342 | 25G416 |
|---|---|---|---|---|---|---|
| IO80211VirtualInterface | 508 | 0x130 | table + size | table + size | table + size | table + size |
| IO80211AWDLProtocol | 571 | 0x130 | size only | size only | table + size | table + size |
| IO80211AWDLPeerManager | 104 | 0x28 | size only | size only | table + size | table + size |

## Result
- **IO80211VirtualInterface** is the same on all four builds: 508 slots, every slot holds the same symbol, the 179 method names of the class are the same, instance size 0x130.
- **IO80211AWDLProtocol** and **IO80211AWDLPeerManager** are the same on 25G342 and 25G416, slot for slot and name for name. Their instance sizes (0x130 and 0x28) are the same on all four builds.
- Not done by us: the slot tables of the two AWDL classes on 25G241 and 25G332. The sizes agree, and 25G332 and 25G342 carry the same kernel version (xnu-12377.161.15.701.48).
- Done by DrogaBox (2026-11-14, [his comment](https://github.com/DrogaBox/RTL8814Native/issues/1#issuecomment-6880671494)): he dumped both AWDL classes from the 25G241 and 25G332 kernel collections with IDA and compared them with our 25G416 tables. Same symbol in every slot, 571 and 104 slots. That is his measurement, not ours; we have not seen his tables yet. Confidence for "nothing moved from 25G241": Medium for our own data, High once the two results are read together.
